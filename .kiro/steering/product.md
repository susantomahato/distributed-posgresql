# PostgreSQL

PostgreSQL is an advanced open-source object-relational database management system (ORDBMS) that supports an extended subset of the SQL standard.

## Key Features

- ACID-compliant transactions
- Foreign keys, subqueries, triggers
- User-defined types and functions
- Advanced indexing (B-tree, hash, GiST, GIN, BRIN)
- Multi-version concurrency control (MVCC)
- Write-ahead logging (WAL)
- Point-in-time recovery
- Streaming replication
- Extensible architecture with contrib modules
